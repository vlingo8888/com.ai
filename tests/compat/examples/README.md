# Official Next.js examples

Unmodified copies of App Router examples from [vercel/next.js/examples](https://github.com/vercel/next.js/tree/canary/examples)
(commit `e2e7393`, MIT license, © Vercel, Inc.). Each folder only adds a `compat.json` with the
checks `bun tests/compat/run.ts` runs against `com dev`: the apps themselves must run without changes (ROADMAP P2).
